# اکوسیستم ربات‌های هوشمند اسرائیل 🇮🇱

## مقدمه
این پروژه یک اکوسیستم کامل و یکپارچه از ربات‌های دیسکورد برای سرور رول‌پلی (RP) فوق واقع‌گرایانه با محوریت کشور اسرائیل است. هدف نهایی، خلق یک دنیای مجازی زنده، پویا و هوشمند است که در آن ربات‌ها نه تنها به عنوان ابزارهای مدیریتی، بلکه به عنوان شخصیت‌های فعال و تأثیرگذار در بازی عمل می‌کنند.

## ویژگی‌های کلیدی
- 🤖 **ربات مرکزی ستاره داوود**: مغز متفکر کل سیستم
- 🛡️ **سامانه‌های دفاعی**: گنبد آهنین، فلاخن داوود، خِتْس ۳ و ۴، تاد
- ⚔️ **ربات‌های نظامی**: فرماندهی کل ارتش، نیروهای سه‌گانه، موساد، واحد ۸۲۰۰
- 💰 **ربات‌های اقتصادی**: بانک مرکزی، صنایع نظامی، بازار بورس
- 🏛️ **سیستم دولت و کنست**: انتخابات، قانون‌گذاری، تشکیل کابینه
- 🎭 **زندگی مدنی**: مشاغل، آموزش، املاک، احزاب سیاسی
- 🌍 **شبیه‌سازی محیطی**: چرخه شب و روز، آب و هوا، منابع استراتژیک
- 🎵 **رادیو اسرائیل**: موزیک و اعلان‌های صوتی دولتی

## پیش‌نیازها
- Python 3.8 یا بالاتر
- Discord Developer Account
- Google Gemini API Key
- سرور Discord با دسترسی‌های مدیریتی

## نصب و راه‌اندازی

### ۱. کلون کردن پروژه
```bash
git clone <repository-url>
cd israel-rp-bot-ecosystem
```

### ۲. نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### ۳. تنظیم متغیرهای محیطی
```bash
cp .env.example .env
```
سپس فایل `.env` را ویرایش کرده و مقادیر واقعی را وارد کنید:
- توکن‌های ربات‌های دیسکورد
- کلید API گوگل Gemini
- شناسه سرور و رول‌های مدیریتی

### ۴. راه‌اندازی ربات‌ها
هر ربات را به صورت جداگانه اجرا کنید:

```bash
# ربات مرکزی ستاره داوود
python bots/magen_david.py

# ربات‌های دفاعی
python bots/iron_dome.py
python bots/davids_sling.py
python bots/arrow.py
python bots/thaad.py

# ربات‌های نظامی
python bots/military.py
python bots/mossad.py
python bots/unit8200.py

# ربات‌های اقتصادی
python bots/economy.py

# رادیو اسرائیل
python bots/radio.py
```

## کامندهای اصلی

### ربات مرکزی (ستاره داوود)
- `!initialize_israel` - راه‌اندازی کامل سرور
- `!apply_citizenship` - درخواست شهروندی
- `!propose_law` - پیشنهاد قانون
- `!vote` - رأی‌گیری
- `!control_panel` - داشبورد کنترل مرکزی

### ربات‌های دفاعی
- `!defcon [سطح]` - تنظیم سطح آمادگی دفاعی
- `!scan_user @کاربر` - اسکن کاربر مشکوک

### ربات‌های نظامی
- `!mission` - دریافت مأموریت جدید
- `!gather_intel` - جمع‌آوری اطلاعات

### ربات‌های اقتصادی
- `!balance` - مشاهده موجودی
- `!transfer @کاربر مقدار` - انتقال پول
- `!buy_property شهر` - خرید ملک
