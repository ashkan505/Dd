## 🚀 نصب و راه‌اندازی

### پیش‌نیازها

```bash
# Python 3.8 یا بالاتر
python --version

# Git
git --version
```

### 1. دانلود پروژه

```bash
git clone https://github.com/your-repo/israel-rp-bots.git
cd israel-rp-bots
```

### 2. نصب وابستگی‌ها

```bash
# ایجاد محیط مجازی
python -m venv venv

# فعال‌سازی محیط مجازی
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# نصب پکیج‌ها
pip install -r requirements.txt
```

### 3. پیکربندی

```bash
# کپی فایل نمونه تنظیمات
cp .env.example .env
```

سپس فایل `.env` را ویرایش کنید:

```env
# Discord Bot Tokens
MAGEN_DAVID_TOKEN=your_central_bot_token_here
IRON_DOME_TOKEN=your_iron_dome_bot_token_here
DAVID_SLING_TOKEN=your_david_sling_bot_token_here
# ... سایر توکن‌ها

# Google Gemini AI API Key
GEMINI_API_KEY=your_gemini_api_key_here

# Server Configuration
MAIN_GUILD_ID=your_discord_server_id_here
ADMIN_USER_IDS=admin_user_id_1,admin_user_id_2
```

### 4. ایجاد ربات‌ها در Discord

1. به [Discord Developer Portal](https://discord.com/developers/applications) بروید
2. برای هر ربات یک Application جدید ایجاد کنید
3. Bot Token را کپی کرده و در `.env` قرار دهید
4. مجوزهای لازم را فعال کنید:
   - `Manage Server`
   - `Manage Roles`
   - `Manage Channels`
   - `Manage Messages`
   - `Read Messages`
   - `Send Messages`
   - `Use Slash Commands`

### 5. دریافت Gemini API Key

1. به [Google AI Studio](https://ai.google.dev/) بروید
2. یک API Key جدید ایجاد کنید
3. کلید را در `.env` قرار دهید

### 6. اجرای ربات‌ها

#### اجرای همه ربات‌ها:
```bash
python run_all_bots.py
```

#### اجرای ربات خاص:
```bash
# ربات مرکزی
python magen_david_bot.py

# گنبد آهنین
python iron_dome_bot.py

# فلاخن داوود
python david_sling_bot.py

# خِتْس ۳
python arrow_defense_bots.py arrow3

# خِتْس ۴
python arrow_defense_bots.py arrow4

# تاد
python thaad_bot.py

# فرماندهی کل ارتش
python army_command_bot.py
```

## 🔧 عیب‌یابی

### مشکلات رایج

#### 1. خطای توکن نامعتبر
```
discord.errors.LoginFailure: Improper token has been passed
```
**راه‌حل**: بررسی صحت توکن‌ها در فایل `.env`

#### 2. خطای مجوزها
```
discord.errors.Forbidden: 403 Forbidden
```
**راه‌حل**: بررسی مجوزهای ربات در سرور

#### 3. خطای Gemini API
```
google.generativeai.types.BlockedPromptException
```
**راه‌حل**: بررسی محتوای پرامپت و کلید API

### لاگ‌ها

لاگ‌های سیستم در فایل `israel_rp_bots.log` ذخیره می‌شوند:

```bash
# مشاهده لاگ‌های زنده
tail -f israel_rp_bots.log

# جستجو در لاگ‌ها
grep "ERROR" israel_rp_bots.log
```
