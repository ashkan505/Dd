## 🚀 نصب و راه‌اندازی

### مرحله 1: دانلود پروژه
```bash
git clone https://github.com/your-repo/israeli-rp-bots.git
cd israeli-rp-bots
```

### مرحله 2: نصب وابستگی‌ها
```bash
# ایجاد محیط مجازی (توصیه می‌شود)
python -m venv venv
source venv/bin/activate  # Linux/Mac
# یا
venv\Scripts\activate     # Windows

# نصب وابستگی‌ها
pip install -r requirements.txt
```

### مرحله 3: تنظیم متغیرهای محیطی
```bash
# کپی کردن فایل نمونه
cp .env.example .env

# ویرایش فایل .env
nano .env  # یا هر ادیتور دیگر
```

### مرحله 4: ایجاد Bot Applications در Discord
1. به [Discord Developer Portal](https://discord.com/developers/applications) بروید
2. برای هر ربات یک Application جدید ایجاد کنید
3. توکن هر ربات را در فایل `.env` قرار دهید
4. مجوزهای لازم را به ربات‌ها بدهید:
   - `Send Messages`
   - `Manage Messages` 
   - `Manage Channels`
   - `Manage Roles`
   - `Administrator` (برای ربات مرکزی)

### مرحله 5: دریافت Gemini API Key
1. به [Google AI Studio](https://makersuite.google.com/) بروید
2. یک API Key جدید ایجاد کنید
3. آن را در فایل `.env` قرار دهید

### مرحله 6: اجرای اکوسیستم
```bash
# اجرای کامل اکوسیستم
python run_all_bots.py

# یا اجرای تک‌تک ربات‌ها
python magen_david_bot.py
python economic_bots.py
python civil_systems.py
python crisis_management.py
```

## 🤖 ربات‌ها و قابلیت‌ها

### 🌟 ربات مرکزی (ستاره داوود)
**پیشوند دستورات:** `!`

**قابلیت‌های کلیدی:**
- راه‌اندازی کامل سرور با یک دستور
- سیستم شهروندی پیشرفته
- مدیریت دولت و انتخابات
- دیپلماسی بین‌المللی
- رویدادهای تصادفی هوشمند
- شبیه‌سازی محیطی (شب/روز، آب و هوا)

### 🛡️ ربات‌های دفاعی

#### گنبد آهنین
- مقابله با اسپم پیام‌های سریع
- انیمیشن رهگیری موشک
- مدیریت موجودی موشک‌ها

#### فلاخن داوود  
- دفاع در برابر منشن اسپم
- تشخیص لینک‌های مخرب
- مقابله با raid (ورود ناگهانی کاربران)

#### خِتس ۳ و ۴
- مقابله با حملات فاجعه‌بار (نوکینگ)
- بازسازی خودکار سرور
- گزارش‌دهی کامل خسارات

#### تاد
- اسکن پیشگیرانه کاربران جدید

## 🤝 مشارکت

### نحوه مشارکت
1. **Fork** کردن پروژه
2. ایجاد **شاخه جدید** (`git checkout -b feature/AmazingFeature`)
3. **Commit** تغییرات (`git commit -m 'Add some AmazingFeature'`)
4. **Push** به شاخه (`git push origin feature/AmazingFeature`)
5. ایجاد **Pull Request**

### راهنمای توسعه
- کد را **تمیز و خوانا** بنویسید
- **کامنت‌گذاری** مناسب انجام دهید
- از **type hints** استفاده کنید
- **تست** کدهای جدید را انجام دهید
- **مستندات** را به‌روزرسانی کنید
